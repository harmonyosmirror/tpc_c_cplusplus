# libtasn1_4_19_0三方库说明
## 功能简介
libtasn1 是 GNU 的 ASN.1 结构编解码库，用于解析和生成 DER/BER 编码的 ASN.1 数据。libtasn1_4_19_0 是 libtasn1 4.19.0 的独立 Lycium 包，与 community/libtasn1（仍可保持旧版本）并存，使用不同的 pkgname 和安装前缀，供 community/gnutls 使用。

## 三方库版本
- 4.19.0

## 已适配功能
- 提供 ASN.1 结构定义解析功能。
- 提供 DER/BER 编解码功能。
- 提供 ASN.1 结构验证功能。
- 支持多架构交叉编译（armeabi-v7a、arm64-v8a）。
